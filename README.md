# PostPath — GDS to IPoS Career Roadmap

A polished, responsive single-page React + Vite website based on the supplied GDS → IPoS roadmap brief.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Included
- Animated hero / route-map visual
- Track A / Track B interactive switch
- Expandable career stages
- Institutional rules cards
- Strategy notes
- Client-side timeline calculator
- Responsive mobile-first layout
- Accessibility-minded semantic buttons and contrast
- No backend and no personal data storage

## Content note
The site uses the supplied brief as its source content. The calculator intentionally uses illustrative progression offsets rather than inventing official eligibility rules; verify official Department of Posts notifications and manuals before personal planning.
